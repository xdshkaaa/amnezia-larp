LarpmneziaVPN — тестовая сборка для macOS

1. Откройте LarpmneziaVPN-test.pkg и пройдите установку.
   Пароль администратора нужен для установки локальной VPN-службы.
2. Запустите LarpmneziaVPN из папки «Программы».
3. Добавьте свой VPN-сервер или импортируйте конфигурацию AmneziaVPN.
4. Откройте Настройки → Приложение → Имя пользователя.
   Подпись по умолчанию: «вконтакте.ком». Это локальное отображаемое имя.
5. На главном экране включите VPN красным переключателем.
   Статус «подключен» появляется только после установки VPN-соединения.

Сборка подписана локальной ad-hoc подписью, без нотарификации Apple.
Если macOS блокирует установщик: Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть.

Профиль VPN и ключи в установщик не включены.
Не включайте два VPN-клиента одновременно: они меняют маршруты системы.

Основано на AmneziaVPN, распространяется на условиях GPL-3.0.
Исходники изменений и инструкция сборки находятся в репозитории amnezia-larp.
